What will happen
  1. The model uses the title, description, cook time, and ingredient list above as prompts.
  2. It returns a structured recipe: refined title, 1–3 sentence description, ingredients with quantities / units, and an ordered step list.
  3. A new Recipe row is created in your library.
  4. Canonical Ingredient rows and Instruction rows get linked to the new Recipe.
  5. This meal gets attached (meal.recipe = new_recipe) and the AI badge is cleared from its planner card.

If no API key is configured (or the model call fails for any reason), a basic Recipe is built from the on-file data so the click is still productive. The basic Recipe lands on the same Recipe-detail page where you can edit title, ingredients, and steps.
